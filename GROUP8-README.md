# Town — Group 8: Private / Beta Launch

This group adds the controlled beta launch layer.

## Included
- Beta tester status table
- Initial controlled cohort enrollment for existing accounts
- Beta launch/status page
- Six-part beta testing checklist
- Local checklist progress persistence
- Direct links to feedback and community testing
- Beta status in the footer

## Supabase
Run:

`supabase/stage8-beta-launch.sql`

The SQL is safe to run after the previous stages.

## Frontend
Run:

`npm run build`

Then open:

`#/beta`
